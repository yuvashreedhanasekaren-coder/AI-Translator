# AI Translator 🌐

An AI-powered multilingual translation application that helps users translate **text, images, uploaded videos, YouTube videos, and live audio/meetings** into their preferred language.

The project combines speech recognition, machine translation, text-to-speech, and video/audio processing to provide an end-to-end translation experience.

## ✨ Features

* 📝 **Text Translation** – Translate text between supported languages.
* 🖼️ **Image Translation** – Extract and translate text from images.
* 🎥 **Video Translation** – Translate speech from uploaded videos and generate translated audio.
* ▶️ **YouTube Translation** – Translate content from YouTube videos.
* 🎙️ **Speech-to-Text** – Convert spoken audio into text using AI-based speech recognition.
* 🔊 **Text-to-Speech** – Generate natural audio from translated text.
* 🗣️ **Live Translation** – Support for real-time speech transcription and translation.
* 🌍 **Multilingual Support** – Designed to support multiple input and output languages.
* 💻 **Web Interface** – Simple interface for selecting languages and performing translations.

## 🔄 Translation Workflow

The application follows a pipeline-based approach:

**Input → Speech/Text Extraction → Translation → Text-to-Speech → Output**

For video translation, the system extracts the audio from the video, converts speech into text, translates the text into the selected language, generates translated speech, and processes the final output.

## 🎯 Project Goal

The main goal of this project is to build a **single AI-based translation platform** capable of handling different types of content such as text, images, videos, YouTube content, and live speech.

It focuses on combining multiple AI and multimedia technologies into one practical application.
